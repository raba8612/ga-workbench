# 總務 AI 工作台

對照總務職缺的五項工作內容，示範如何運用 AI 工具，把總務作業整理成可追蹤、可決策的流程。單一 `index.html`，不需要建置或後端。

**線上版：** https://raba8612.github.io/ga-workbench/

## 模組

| 職缺工作 | 模組 |
|---|---|
| 評估導入 AI 工具 | AI 導入評估：工時比較（保守／自動化兩種情境） |
| 資產管理與活化 | 資產活化：依閒置天數、使用率、帳面價值給出調撥／共享／處分／汰換建議 |
| 辦公空間改裝 | 空間使用分析：會議室時段熱圖與改裝建議 |
| 供應商評價、公務車管理 | 權重可調的供應商評分卡；派車推薦、撞期檢查、到期提醒、減車成本試算 |
| 年度活動（家庭日） | 人數、預算、接駁試算與倒數時程 |

## 資料說明

公司內部資料（財產、車輛、供應商、會議室）皆為模擬。耐用年數、牌照稅等外部數字已查證公開資料，查不到的標為假設，出處列在頁面的「數據來源」頁。
